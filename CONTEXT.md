# Product Reasoning Vocabulary

Use these terms consistently when discussing or extending this repository.

- **Outcome** — the change in the user's world the product should create.
- **Decision** — something the user, system, or product must understand, choose, or commit to.
- **Timeline** — the experience across states before, during, and after an action.
- **Reversible** — cheap to change without migration, durable contracts, retraining, or user harm.
- **Consequential** — creates meaningful future cost, coupling, semantics, risk, or user expectations.
- **Artifact** — the smallest thing that makes a decision inspectable: prose, diagram, prototype, or production implementation.
- **Prototype** — throwaway code built to answer a specific question.
- **Flea move** — a divergent jump that escapes the current solution space.
- **Ant move** — convergent refinement that makes an idea useful and buildable.
- **Evidence** — observed or measured information, distinct from interpretation, assumption, and proposal.
