# Acknowledgements

Product Reasoning is an original agent skill assembled from product-design practice, iterative use with coding agents, and public educational material.

## Product-design video inspiration

The early version was shaped through discussion of these videos and transcripts:

- https://www.youtube.com/watch?v=gr0Val2QSbM — prompted the core framing around decisions/outcomes, user psychology, and experience across time.
- **How I Use AI as a Product Designer (4 Real Workflows)** — influenced the separation between tool/context access and product judgment, and the use of low-fidelity exploration before commitment.
- https://www.youtube.com/watch?v=1iOAdR4Vjto — **The Method I Use When I Have Zero Ideas**; influenced the creative-exploration loop, divergent/convergent thinking, ant/flea moves, lateral reframing, and bad-idea inversion.

No transcript text is included in this repository. Ideas have been independently restated as agent-operational guidance.

## Agent-skill authoring reference

Matt Pocock's open-source skills repository was used as a structural reference:

https://github.com/mattpocock/skills

In particular: small composable skills, progressive disclosure, precise context pointers, leading vocabulary, and throwaway prototypes that answer a specific question.

## Earlier foundations

The concepts in the creativity material also overlap with long-standing work on divergent/convergent thinking, lateral thinking, staged creativity processes, and Alan Dix's “ant and flea” metaphor. The skill treats these as practical reasoning techniques rather than claims of novelty.
