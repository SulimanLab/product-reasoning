# Code of Conduct

## Our standard

This project welcomes thoughtful, good-faith participation from people with different backgrounds and levels of experience.

Be respectful, specific, and constructive. Critique ideas and behavior, not people. Assume good intent until there is evidence otherwise, and correct misunderstandings without hostility.

Examples of welcome behavior include:

- explaining the failure mode behind a proposed change;
- disagreeing with a design choice while staying focused on evidence and trade-offs;
- giving contributors room to learn;
- crediting prior work and sources;
- keeping discussions relevant to the project.

Unacceptable behavior includes harassment, personal attacks, discrimination, threats, deliberate disruption, doxxing, or publishing another person's private information without permission.

## Scope

This code applies in repository issues, pull requests, discussions, reviews, and other project spaces.

## Enforcement

Maintainers may edit, hide, lock, or remove contributions that violate this code and may restrict participation when necessary to protect the project community.

If you need to report conduct privately, request a private contact channel from the maintainer without posting sensitive details publicly.

## Attribution

This policy is intentionally concise and project-specific. It is informed by common open-source community standards, including the Contributor Covenant, without reproducing that text.
