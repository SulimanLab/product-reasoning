# Diagnostics

Identify the mechanism before changing the text.

## A. Syntax / sentence frame

Typical signals:

- unnecessary explicit subjects;
- source-language word order;
- existential openings copied mechanically;
- conditional meaning expressed with temporal structure;
- repeated tense/future marking;
- a noun-heavy English frame carried intact into Arabic.

Example:

❌ `هناك ثلاثة مواضيع متبقية لك.`

✅ `بقيت لك ثلاثة مواضيع.`

Do **not** conclude that `هناك` is forbidden. The issue is whether it is doing real work.

## B. Particles and prepositions

Signal: the Arabic preposition looks chosen because it is the first dictionary equivalent of the source preposition.

Example:

❌ `يمكنك تحديث بياناتك من خلال التطبيق.`

✅ `يمكنك تحديث بياناتك في التطبيق.`

The source relation is interface/location, not literal passage “through.”

## C. Morphology displaced by analytic phrasing

Signal: a simple Arabic form has been replaced by several helper words because the source language uses several words.

Examples:

🟡 `القيام بتحديث البيانات`

✅ `تحديث البيانات`

🟡 `الأكثر وضوحًا` may be fine in some contexts.

✅ `أوضح` is often lighter when the grammar and meaning permit it.

Do not force obscure derived forms merely because they exist.

## D. Semantic calque

Signal: the Arabic word is valid but its combination or intended meaning feels imported.

Source idea:
`What does anxiety look like for you?`

❌ `كيف يبدو القلق بالنسبة لك؟`

✅ `كيف يظهر القلق عندك؟`

The issue is the imported metaphor, not the word `يبدو` by itself.

## E. Rhetorical / metaphorical calque

Signals:

- translated self-help slogans;
- English corporate metaphors;
- copied transition rhythm;
- “in every step of your journey” language that survives only because the source used it.

Example:

❌ `ابدأ رحلتك لتصبح أفضل نسخة من نفسك.`

Possible rewrite:

✅ `ابدأ بخطوة تساعدك على فهم نفسك أكثر.`

Or simply:

✅ `ابدأ`

The correct rewrite depends on the actual promise.

## F. Bureaucratic scaffolding

Signals:

- `قم بـ`;
- `القيام بـ`;
- `عملية` before an ordinary action;
- `الخاص بك` where a suffix is enough;
- success messages padded with `بنجاح`;
- repeated `يرجى`;
- UI narration such as `اضغط على الزر أدناه`.

Example:

❌ `يرجى القيام بإدخال البريد الإلكتروني الخاص بك.`

✅ `أدخل بريدك الإلكتروني.`

## G. Back-translation smell test

Translate the Arabic mentally back into the source language.

If syntax, word order, and phrase boundaries line up unusually well, inspect for transfer.

Do not use this as a binary classifier: Arabic and English sometimes genuinely share simple structures.

## Severity

### 🔴 Change

- meaning distorted;
- source frame clearly visible;
- phrase is unnatural to a competent Arabic reader;
- user comprehension or trust suffers.

### 🟡 Improve if useful

- acceptable but heavy;
- formally inflated;
- literal but not damaging;
- a lighter native construction is obvious.

### 🟢 Leave

- natural, clear, and appropriate;
- modern usage is established;
- alternative would be more archaic, less clear, or merely different.
