# Sources

## Primary conceptual reference

**أحمد الغامدي — العَرَنجية: بلسان عربي هجين**

The skill takes from the book's central problem framing: modern Arabic can remain grammatically Arabic while importing foreign structures into syntax, morphology, lexical meaning, and style.

This repository does not reproduce the book. It operationalizes the ideas as diagnostic tests for writing agents.

## Important methodological guardrail

The skill deliberately does **not** treat every modern expression as corruption. The author's 2025 essay itself emphasizes the need for more methodological qualifications and warns against turning the subject into combative overcorrection.
