# Design System

A design system is a constraint and a vocabulary, not product judgment.

## Inspect before inventing

Before creating a new pattern:

- inspect the relevant design-system component/variant;
- inspect the current production implementation;
- reuse established patterns when they express the intended experience;
- avoid near-duplicates created for local convenience.

## When consistency is wrong

A perfectly consistent interface can preserve a bad decision model.

If the existing pattern creates real product friction, name the problem first, then propose the smallest justified deviation. A broadly reusable new pattern is a consequential decision; ask before establishing it if it creates future system cost.
